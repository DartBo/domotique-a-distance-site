# Domotique à Distance — MVP

Service d’assistance à distance pour Home Assistant, Zigbee et maison connectée.

## Règle de lancement
**0 € de coût fixe avant le premier client.**

- GitHub Free pour le code
- hébergement statique gratuit
- sous-domaine gratuit au départ
- formulaire gratuit
- suivi prospects gratuit
- paiement sans abonnement mensuel
- publicité payante : aucune au lancement
- nom de domaine : aucun achat avant validation du marché

## Positionnement
**Domotique à Distance**
*Votre domotique, enfin simple.*

Le service porte sur la configuration logicielle à distance. Aucun câblage ni travail électrique n’est inclus.
