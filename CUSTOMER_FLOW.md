# Parcours client

1. Le prospect découvre le service.
2. Il consulte le site.
3. Il remplit le pré-diagnostic gratuit.
4. La demande est qualifiée.
5. Le pack adapté est proposé.
6. Le client accepte le périmètre.
7. Le paiement est effectué.
8. Le rendez-vous à distance est fixé.
9. Une sauvegarde est faite.
10. L’accès temporaire est créé si nécessaire.
11. Intervention : observer → sauvegarder → modifier → tester → valider.
12. Un compte rendu court est envoyé.
13. Suivi pendant 7 jours sur la modification réalisée.
14. L’accès temporaire est supprimé.
15. Un avis est demandé si le dossier est résolu.

## Règle de rentabilité
Une demande trop large pour le pack 99 € est recadrée, transformée en optimisation ou refusée avant paiement.
